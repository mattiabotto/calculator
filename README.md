# calculator
A basic calculator, with similar functionalities and design as the one in Windows

## Functionalities
- \+ - * / and % (percentage) operators, with C and CE
- Possibility to use parenthesis also in basic mode (Windows standard mode is automatically executing operations after each operator, so it is not possible to execute something like 2 + 3 * 4 giving precedence to the multiplication). This can be added as a optional functionality, first maybe try the simpler automatic execution.
- Input: can be both  from GUI (clicking on buttons) and from keyboard (to add later)
