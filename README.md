# calculator
A basic calculator, with similar functionalities and design as the one in Windows

## Functionalities
- \+ - * / and % (percentage) operators, with C, CE, backspace and negate operator
- Input: can be both  from GUI (clicking on buttons) and from keyboard (to add later)
- Can chain operations (for example enter 5 + 9 + will make the calculation and be ready showing 14 + for the next operation)
- Pressing '=' after an operation will continue doing the operation with the result as first operand

## Project description
The application is a basic calculator with very similar functionalities and functioning to the one available as default in Windows. A simple but good looking design is made with HTML + CSS and the logic is handled with Javascript on the client size. 
Different cases of input are handled in order to offer an intuitive experience, showing the results on the screen.

## Skills and technologies demonstrated
- Basic design of a GUI with CSS flexbox implementation
- Use of eventListeners and callback functions for the calculator's logic
- Handling of hedge cases and user's input
